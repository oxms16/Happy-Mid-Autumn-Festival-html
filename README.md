# 中秋快乐 · 粒子祝福网页

一个使用原生 HTML、CSS 和 JavaScript 制作的中秋节动态祝福页面。打开网页后，金色祝福文字从上向下流动，白色粒子依次组成倒计时与祝福语，随后彩色祝福卡片排列成爱心，并逐张铺满屏幕。

项目不依赖框架、服务器或在线资源，页面动画与音乐均已封装在单个 HTML 文件中，适合直接发送和离线打开。

## 效果流程

1. 点击“开启祝福”，同时开始播放音乐和动画。
2. 金色中秋祝福文字从屏幕顶部持续向下流动。
3. 白色圆点组成 `3 → 2 → 1` 粒子倒计时。
4. 粒子依次变化为：
   - 亲爱的
   - 祝你
   - 中秋快乐
   - 岁岁无忧
5. 彩色横向祝福卡片逐张组成爱心。
6. 卡片逐张出现并铺满屏幕，最后显示中秋祝福。

## 主要特点

- 单文件运行，无外部依赖
- 支持离线打开
- 自适应手机竖屏和电脑横屏
- Canvas 粒子文字变形动画
- 长短不一的金色文字雨与渐隐效果
- 彩色祝福卡片爱心动画
- 内置音乐开关与“再看一次”按钮
- 针对高分辨率屏幕与移动端性能进行适配

## 使用方法

直接下载并打开 [`中秋快乐.html`](./中秋快乐.html) 即可。

在手机上使用时，建议先将文件下载到本地，再选择浏览器打开。由于手机浏览器的自动播放限制，需要点击一次“开启祝福”，音乐和动画才会开始。

也可以使用 GitHub Pages 在线展示：

1. 将项目上传到 GitHub 仓库。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择从分支部署。
4. 选择包含网页文件的分支与根目录并保存。

如需让 GitHub Pages 默认打开页面，可以将 `中秋快乐.html` 重命名为 `index.html`。

## 自定义

页面所有代码都位于 `中秋快乐.html` 中，可直接使用文本编辑器修改：

- `rainTexts`：背景金色祝福语
- `stages`：中央粒子文字及停留时间
- `cardTexts`：彩色卡片上的祝福语
- `cardColors`：卡片底部颜色
- `<audio id="bgm">`：内嵌背景音乐

## 浏览器兼容性

建议使用近期版本的 Chrome、Edge、Safari 或其他 Chromium 内核浏览器。部分聊天软件不能直接预览 HTML 文件，此时需要先下载，再使用系统浏览器打开。
